# 知行完整备份格式（v1）

## 1. 导出入口

设置 → 数据与备份 → 完整数据备份：

- **ZIP**：完整备份（推荐恢复）。
- **JSON**：单文件可读备份，不含附件二进制。
- **Markdown**：面向阅读/迁移的全文。
- **CSV**：多表 ZIP，便于表格工具打开；不是恢复格式。
- **PDF**：Canvas 排版后嵌入 JPEG 的报告；不是恢复格式。

浏览器预览没有 SQLite 业务库，完整备份入口显示“需桌面壳”；上方偏好
备份仍可用。完整备份只在 Tauri 桌面壳内启用。

## 2. ZIP 结构

```
manifest.json
data/entities.json          # 除画板外的全部业务行 + 外观 + 白名单偏好
data/relations.json         # 关系数组、类型计数、悬空引用
boards/<board-id>.json      # { version, board, nodes, edges }
attachments/<sha256>.<ext>  # 附件二进制（内容寻址）
```

### manifest.json 关键字段

| 字段 | 说明 |
|---|---|
| `app` / `kind` / `formatVersion` | `zhixing` / `backup` / `1` |
| `exportedAt` / `appVersion` / `schemaVersion` | 导出时间、应用版本、SQLite schema |
| `counts` | 每类对象数量（含画板节点/连线、回收站行） |
| `entries` | 除 manifest 外每个文件的字节数与 SHA-256 |
| `attachments` | 附件 id、文件名、MIME、SHA-256、大小、ZIP 路径或 `null` |
| `boards` | 画板 id、标题、路径、SHA-256、节点/连线数 |
| `relations` | 关系总数、按类型计数、悬空关系 |
| `settings` | 导出的白名单键与被排除的键名 |
| `security` | 明确声明不含账号/令牌/密钥/密码 |

导入会逐项校验：路径安全、条目数量/大小、CRC32、manifest 中每个文件的
SHA-256 与字节数、画板文件、附件 SHA-256、对象计数、relations 与业务
数据是否一致。任何一项失败都拒绝打开恢复预览。

## 3. 数据完整性

- 所有列表使用 `includeDeleted` 导出，回收站对象与关系一起进入备份。
- 画板以“画板 + 节点 + 连线”为单位；连线端点必须存在。
- 关系不会在导出/恢复时被改写成 `null`；指向不存在对象的关系会作为
  悬空关系警告，并阻止相关行写入。
- 时间戳、`version` 由本机写入时重新生成；对象 id、外键、软删除状态
  与附件哈希会被保留。恢复不是数据库页级还原。
- 附件二进制在 IndexedDB 中按 `attachments/<sha256>` 内容寻址；导出前
  重新计算哈希，损坏文件不会冒充有效附件。

## 4. 恢复语义

1. 解析备份 → 校验 manifest/哈希/关系 → 收集本机当前数据；
2. 打开“恢复预览”：新增 / 冲突 / 跳过 / 阻止 / 未变化、附件二进制数量、
   冲突对比与内容摘要；
3. 冲突默认 **跳过（保留本机）**；覆盖必须勾选“允许覆盖本机同 ID 对象”，
   “保留两者”生成新 id 并重映射引用；
4. 用户点击“确认恢复”后才逐项写库。父对象先于子对象写入，删除放在最后；
5. 任一步失败立即停止，显示已应用数量与失败位置，不把失败显示为成功。

### 已知限制（不得在发布说明中省略）

- 恢复按对象逐项调用既有 IPC，没有跨对象事务；中途失败会留下已写入的
  部分数据，界面会明确报告，不提供自动回滚。
- 任务/笔记的时间戳与版本号不保留；复盘快照按日期范围唯一，无法覆盖或
  复制冲突快照。
- 已删除的复盘快照、已删除的设备偏好不恢复。
- 打卡记录通过 `habit_logs_set` 写入，id 不保留；`done=false` 的记录会
  以回收站状态恢复。
- “保留两者”会复制笔记的直属块/待办、任务的子任务；跨对象引用（如任务
  指向笔记）在未变化时仍指向本机原对象。画板会复制全部节点与连线。
- JSON/Markdown/CSV/PDF 都不含附件二进制；只有 ZIP 含附件。

## 5. 安全边界

- 设置表只导出 `SETTING_KEYS` 白名单；未知键默认排除并在 manifest 列名。
- 不读取/不导出 localStorage 中的 WebDAV 配置、同步游标、设备令牌、
  账号或设备密钥。
- 导入时任何非白名单设置键都会导致拒绝，避免外部备份把令牌类数据带入。
- 诊断 JSON 只含脱敏后的耗时/错误，不含业务正文或附件内容。
