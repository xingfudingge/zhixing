# 知行 0.1.0 · P2-04 发布说明

## 新增

### 完整数据备份（桌面壳）

- 导出 ZIP：`manifest.json`、业务实体、关系清单、每块画板 JSON、附件二进制。
- 导出 JSON：单文件业务数据与 manifest，不含附件二进制。
- 导出 Markdown：笔记、任务、画板、附件哈希、关系与白名单偏好。
- 导出 CSV：多表 ZIP，含 UTF-8 BOM 与 manifest。
- 导出 PDF：Canvas 排版的中文报告，按 A4 分页；**文字是图像，不可选中或检索**。
- 导出前校验附件大小与 SHA-256；缺失/损坏附件只恢复元数据并明确提示。
- 设置表只导出白名单偏好；不导出账号、设备令牌、密钥、WebDAV 密码、
  同步游标、账号或设备密钥。

### 恢复预览

- 先解析并校验 manifest、文件哈希、画板、附件、对象计数与关系，再显示预览。
- 展示新增 / 更新 / 回收站 / 跳过 / 阻止 / 未变化数量。
- 冲突逐项展示本机与备份的标题、时间和内容摘要。
- 默认“跳过（保留本机）”；“覆盖本机”需额外勾选确认；“保留两者”生成
  新 ID 并重映射引用，笔记/任务会复制直属块/待办/子任务。
- 父对象跳过时，新增子对象被阻止，不会悄悄挂到本机旧父级。
- 回收站对象与关系一起恢复：删除对象的关系不被改成 `null`。
- 写入失败立即停止并报告已应用数量，不把部分成功显示为成功。

### 可访问性

- P2-04 新增 Modal：`role="dialog"`、`aria-modal`、`aria-labelledby/describedby`、
  焦点陷阱、Esc 关闭、关闭后焦点归还、背景滚动锁、`aria-busy`。
- 全局历史对话框焦点兜底：Tab 循环、焦点外逃拉回、关闭归还；
  自带 FocusTrap 的 Modal 不重复接管。

### 诊断

- 内存环形缓冲区记录窗口错误、未处理 Promise、长任务与导出/恢复耗时。
- 设置页可下载脱敏诊断 JSON；不写数据库、不上传。

## 已知限制

- 恢复没有跨对象数据库事务；中途失败会留下已写入的部分数据，界面会报告。
- 时间戳与 `version` 不保留；复盘快照按日期范围唯一，冲突时只能跳过。
- 已删除的复盘快照与偏好不恢复；打卡记录 id 不保留。
- JSON/Markdown/CSV/PDF 不含附件二进制；需要完整附件请用 ZIP。
- PDF 文字不可选中/检索，不是结构化迁移格式。
- 浏览器预览没有 SQLite 业务库，完整备份入口显示“需桌面壳”。
- 没有云备份、定时备份、加密压缩或账号同步。
- “重置全部数据”仍未实现，设置页明确标注“未实现”，本版本不提供该入口。
- 真实桌面壳导出/恢复、PDF 视觉、屏幕阅读器与对比度人工验收尚未执行，
  详见 `checklist.md` 的待办项。
